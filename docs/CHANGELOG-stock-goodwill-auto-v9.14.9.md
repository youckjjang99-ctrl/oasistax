# v9.14.9 — 주가평가 영업권 자동계산

기존 프로젝트 폴더·Git 연결·원래 체크아웃의 미완료 변경은 보존합니다.

## 원인과 변경 내용

기존 주가평가는 사용자가 입력한 영업권을 순자산에 더할 뿐, 영업권 자체를 계산하지 않았습니다. 기존 재무 연도별 순손익과 자산·부채 조정값을 재사용하여 자동계산을 추가했습니다.

1. 신규 평가의 기본 모드는 자동계산입니다. 수동입력과 사유를 기록하는 불산입 모드를 함께 제공합니다.
2. 회사 전체 3개년 순손익을 최신 연도부터 3:2:1로 가중합니다. 주당 순손익이나 자본금과 혼동하지 않습니다.
3. 자기자본은 새 영업권 가산 전 조정 순자산(조정 자산 − 조정 부채 + 기타 순자산 조정)입니다. 신규 영업권을 자기자본에 다시 넣는 순환계산을 방지합니다.
4. 이미 순자산에 포함된 영업권 해당 매입 무체재산권 미상각잔액만 신규 가산액에서 차감합니다. 원래 자산을 삭제하지 않고, 일반 무형자산 전체를 자동 차감하지 않습니다. 기본 0원은 '해당 없음' 가정임을 화면에 명시합니다.
5. 계산 근거, 모드, 수동 보정값, 적용된 영업권, 계산 버전을 평가자료와 함께 저장합니다.
6. 과거 저장자료는 모드가 없으면 수동입력으로 불러와 영업권이 자동으로 달라지지 않게 합니다. 업체 변경 시 새 설정을 모두 초기화하고, 등기정보 연동 시 사용자의 설정을 보존합니다.
7. 마지막 성공 계산의 입력과 결과가 일치할 때만 저장합니다. 실패한 재계산 후 이전 결과를 새 입력과 혼합해 저장하지 않습니다.
8. 저장된 숫자형 주식수·액면가를 문자열 입력칸에 직접 넣어 발생하던 불러오기 오류를 보완했습니다.
9. 기존 계산의 음수 순손익 가중평균·최종 순자산에는 각각 0원 하한을 적용했습니다. 하한 적용 전 원래 값도 결과에 보존하고 화면에 알립니다. 기존 저장자료를 일괄 재계산하거나 덮어쓰지 않습니다.

## 참조 수식과 차이

첨부 Excel은 읽기 전용으로 분석했으며 원본을 변경하지 않았습니다. 고객의 실제 값·원본 Excel은 소스·테스트·ZIP에 포함하지 않습니다.

참조 시트: `영업권`의 X10, B17, I17, P17, B25, K25, T25.

```text
W = (최근 1년 순손익 × 3 + 최근 2년 순손익 × 2 + 최근 3년 순손익) / 6
추가 가산 영업권 = MAX((MAX(W, 0) × 50% − 가산 전 자기자본 × 10%) × 3.7908 − 해당 매입 무체재산권 잔액, 0)
```

원본 기본 시트 B25는 `(B17 − I17 × P17) × 3.7908`, T25는 `MAX(B25 − K25, 0)`입니다. `영업(2)2`도 같은 구조입니다. `영업권3`의 B25는 `(B17 − (I17 × P17) / 3.7908)`로 달라 기본 시트 산식으로 채택하지 않았습니다. 이번 CRM 작업에서 Excel의 이 다른 수식을 수정하지는 않았습니다.

기본 계수 3.7908은 원본과 일치시키기 위한 반올림값입니다. 5년·10% 정밀 현가계수 약 3.790787과 미세한 차이가 있으므로 법정 확정 평가액으로 표시하지 않습니다.

시행령 제59조제3항·제56조제1항에 따라 음수 W는 0원으로 처리합니다. 자기자본이 0 이상인 허용 자동계산 범위에서는 원본 Excel의 최종 영업권과 같습니다. 자기자본이 음수인 특수 경우에는 임의의 세법 해석으로 자동 계산하지 않고 수동/불산입 검토를 요청합니다.

## 세무 검토 범위·제한

- 자동 불러오기 자료는 회계상 당기순이익·장부가액의 초안입니다. 세법상 순손익 및 시가·자산부채 조정은 사용자가 확인해야 합니다.
- 3개년 자료 누락, 연도 중복·역순·불연속, 음수 자기자본, 비정상 수치에서는 자동계산을 차단합니다. 실제 0원과 자료 미확인을 구분합니다.
- 영업권 가산 제외 여부는 자동 확정하지 않습니다. 업력·휴폐업·계속 세무상 결손·부동산 비중·적격 법인전환 예외는 별도 검토합니다.
- `순자산가치만 적용` 선택만으로 영업권을 일괄 제외하지 않습니다. 시행령 제54조제4항의 모든 사유가 영업권 가산 제외와 같은 것은 아닙니다.
- 결산기간 변경·3개년 미만 평가·추정이익 예외·유상증감자 관련 세법 조정은 이번 자동계산의 범위가 아닙니다. 이런 경우 전문가 검토 후 기존 수동 모드를 사용합니다.
- 현재 평가와 영업권을 구현하며, 원본의 미래 성장/정책 시뮬레이션 시트 전체를 이식하지 않습니다.

## Supabase·기존 기능 영향

테이블·컬럼·인덱스·RLS·Storage·고객 ID·company_uid 변경 없음. 기존 valuation_data JSON에 추가 필드를 저장하므로 마이그레이션 SQL 및 별도 검증 DB는 필요하지 않습니다.

추가 JSON 필드: goodwill_mode, goodwill_manual, goodwill_acquired_intangible_remaining, goodwill_exclusion_reason, goodwill_details, goodwill_law_base_date. result에는 가산 전 순자산, 적용 영업권·근거, 0원 하한 전 원래 값이 추가됩니다. 기존 goodwill 필드는 최종 반영 금액으로 유지합니다.

전화번호 수집·영업배정·연락상태·로그인·경정청구/Tilko·기업등록·AI 상담 로직은 수정하지 않았습니다. 계산은 로컬에서 즉시 수행하며 추가 API 호출이나 유료 연산은 없습니다. 실제 고객정보·운영 SQL·Storage 파일은 수정·삭제하지 않았습니다.

## 사용방법

관리자와 일반 사용자 모두 기존 접근권한으로 기업컨설팅 → 주가평가를 엽니다. 3개년 자료 및 자산·부채 조정값을 확인하고 영업권 반영 방식을 선택한 뒤 '주가평가 계산'을 누릅니다. 결과의 '이번 평가에 가산한 영업권'과 '영업권 계산 근거'를 확인하고 저장합니다.

기존 평가를 불러오면 수동 모드입니다. 자동 재평가가 필요할 때만 자동계산으로 바꾸고 다시 계산·저장합니다. 불산입은 검토 사유가 필수입니다. 설정은 폼 안에 있어 모드를 바꾼 뒤 계산 버튼을 눌러 적용합니다. 아직 제출하지 않은 브라우저 편집내용이 아니라 마지막 성공 계산을 저장한다는 안내를 표시합니다.
