# OASIS 개인사업자 검토신청 알림톡 템플릿

버전: `v9.10.0`

아래 문구는 Solapi·카카오 비즈니스 채널 심사용 고정 문구입니다. 영업사원은
본문을 수정할 수 없습니다. 템플릿 ID는 Railway 환경변수로만 등록하며,
승인 전에는 `OASIS_KAKAO_GUIDANCE_SEND_ENABLED=false`를 유지합니다.

공통 변수는 `#{검토신청링크}` 한 개만 사용합니다. 링크에는 업체명, 전화번호,
사업자등록번호, 주민등록번호를 넣지 않습니다. 문자 대체발송은 비활성화합니다.

## 안내 발송번호와 인증번호 분리 원칙

- DB발굴에 저장된 공개 휴대전화 번호는 이 안내 메시지를 보내는 용도로만
  사용합니다.
- 공개 번호는 검토신청 링크, 고객 입력 화면, 홈택스·근로복지공단 간편인증
  요청에 전달하거나 자동 입력하지 않습니다.
- 고객은 검토신청 화면에서 대표자 본인 명의의 휴대전화 번호를 직접
  입력해야 합니다.
- 안내 메시지를 받은 공개 번호와 고객이 직접 입력한 인증용 번호가 달라도
  정상적인 흐름이며 오류로 처리하지 않습니다.
- 고객이 입력한 대표자 이름·생년월일·휴대전화 번호와 간편인증서 가입정보가
  일치하지 않으면 인증이 실패할 수 있음을 입력 화면에서 안내합니다.
- 인증용 번호와 주민등록번호는 공개 발송 연락처와 별도의 암호화된 임시 작업에
  저장하며, 인증 유효시간은 10분, 복구 가능한 작업의 최대 보존시간은 45분입니다.
  작업 완료·실패·취소·만료 시 암호문을 비웁니다. 일반 고객·안내 발송
  테이블에는 원문을 저장하지 않습니다.
- 인증용 번호는 장기 고객 식별 해시나 마스킹 표시값에도 포함하지 않습니다.
  이 번호로 보내는 즉시 2차 인증 안내는 최대 10분만 암호화 보관하고,
  인증 종료 후 완료·실패 알림 발송번호로 재사용하지 않습니다.

## 1. 고용지원금 안내

- 내부 키: `employment_support`
- Railway 템플릿 환경변수:
  `SOLAPI_TEMPLATE_GUIDANCE_EMPLOYMENT_SUPPORT_ID`
- 버튼명: `고용지원금 검토 신청`

```text
안녕하세요. 오아시스 세무회계입니다.

개인사업자 운영 과정에서 확인해볼 수 있는
고용지원 제도와 세제 혜택을 안내드립니다.

지원 가능 여부는 고객님의 동의와 본인인증 후
필요 자료를 확인하여 세무사가 검토해드립니다.

아래 버튼에서 검토 절차를 확인하실 수 있습니다.
```

버튼 링크: `#{검토신청링크}`

- 내부 키: `policy_funding`
- Railway 템플릿 환경변수:
  `SOLAPI_TEMPLATE_GUIDANCE_POLICY_FUNDING_ID`
- 버튼명: `정책자금 검토 신청`

```text
안녕하세요. 오아시스 세무회계입니다.

개인사업자가 검토할 수 있는 정책자금과 지원제도 정보를 안내드립니다.

실제 가능 여부와 진행 방향은 고객님의 동의 및 자료 확인 후
세무사가 검토하여 안내드립니다.

아래 버튼에서 검토 절차를 확인하실 수 있습니다.
```

버튼 링크: `#{검토신청링크}`

- 내부 키: `tax_credit`
- Railway 템플릿 환경변수:
  `SOLAPI_TEMPLATE_GUIDANCE_TAX_CREDIT_ID`
- 버튼명: `세액공제 검토 신청`

```text
안녕하세요. 오아시스 세무회계입니다.

사업 운영 중 적용 여부를 확인해볼 수 있는
세액공제와 세제 혜택을 안내드립니다.

누락 여부와 적용 가능성은 고객님의 동의와 자료 확인 후
세무사가 검토하여 안내드립니다.

아래 버튼에서 검토 절차를 확인하실 수 있습니다.
```

버튼 링크: `#{검토신청링크}`

## 금지 표현

- 지원금 지급 확정
- 환급 확정
- 누락 확정
- 즉시 수령 가능
- 예상 환급금 또는 예상 지원금 금액
- 고용인원 증가 사실 등 DB발굴 원천정보

## 운영 활성화 체크

1. 카카오 비즈니스 채널에서 위 3개 템플릿 승인
2. Railway에 승인된 템플릿 ID 3개 등록
3. `OASIS_KAKAO_GUIDANCE_PROVIDER_MODE=live` 설정
4. `OASIS_KAKAO_GUIDANCE_PHONE_HASH_KEY`에 안내 발송번호 지문용 전용
   비밀키 등록(32자 이상, 인증번호 암호화 키와 분리)
5. 비밀키·채널 ID 등록 상태 확인
6. 개발·테스트 환경에서만 `OASIS_KAKAO_GUIDANCE_MOCK_MODE=true`를 사용하고,
   운영 환경에서는 모의발송이 차단되는지 확인
7. 관리자 화면에서 일일 발송 한도와 템플릿 상태 확인
8. 수신동의·정보성 안내 기준 최종 확인
9. 운영 스모크 테스트 후에만
   `OASIS_KAKAO_GUIDANCE_SEND_ENABLED=true` 적용

환경변수와 관리자 DB 스위치가 모두 활성화된 경우에만 실제 발송할 수 있습니다.
둘 중 하나라도 꺼져 있으면 발송을 차단합니다.
