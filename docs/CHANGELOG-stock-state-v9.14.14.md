# 등기·주가평가 자료 복원과 바로보기

버전: `v9.14.14-stock-state` · 작업일: 2026-10-23 Asia/Seoul

기준: GitHub main `b7e07833f77213d8ce0551372d03e5763c4c7694`. 앞서 준비한 `v9.14.13-registry-context` 등기 업로드 수정도 포함합니다.

## 발견한 원인

1. Streamlit이 보이지 않는 계산 탭의 위젯 값을 정리하지만 자동 로드 표시는 남았습니다. 다시 방문해도 발행주식수·액면가·재무 입력값을 복원하지 않았습니다.
2. 계산 결과와 입력값을 기업별이 아닌 공통 세션 키에 저장했습니다. 업체·메뉴 전환 시 최근 결과가 사라질 수 있었고 일부 평가유형·할증률 위젯은 다른 기업에 남았습니다.
3. 저장 이력은 현재 기업으로 제한되지 않았고, 입력창 생성 후 저장 평가값을 대입해 화면 오류가 발생할 수 있었습니다. 불러오기 함수는 저장된 계산 결과도 지웠습니다.
4. 등기 복원 시 저장일과 무관하게 클라우드 값을 우선했고, 과거 키 복구에서 식별번호 충돌이 있어도 동일 상호로 연결할 수 있었습니다.
5. 평가 수정 저장은 기존 버전을 바꿨고, 클라우드 저장 실패 여부를 확인하지 않고 성공 안내를 표시했습니다.

## 수정 내용

- 사용자와 사업자등록번호로 세션 작업공간을 분리합니다. 메뉴·세무조정 탭 이동, A→B→A 업체 전환 시 회사별 입력·계산 결과·세무조정 검토를 복원합니다. 등록 고객의 업데이트 시각이 바뀌어도 같은 기업의 검토값을 초기화하지 않습니다.
- 초기 진입은 기존 고객 재무정보와 등록 등기를 불러오고, 발행주식수·액면가·자본금을 연결합니다. 기업등록 업로드가 별도의 기업컨설팅 선택 상태를 요구하지 않게 한 앞선 수정도 유지합니다.
- 상단에 ‘등록 자료 · 최근 평가 바로보기’를 배치합니다. 등기 핵심 수치, 저장일, 상세정보, 등록 자료 새로고침, 명시적 현재 평가 반영, 최근 저장 평가 열기를 제공합니다.
- 새로운 등기와 평가 입력값이 다르면 기존 평가를 자동 덮어쓰지 않고 차이 안내와 반영 버튼을 제공합니다. 반영 후에는 재계산이 필요하며 이전 영구 저장 버전은 보존합니다.
- 평가 이력은 현재 기업만 표시합니다. 저장 결과를 원본 그대로 열고 실제 계산 입력값과 결과의 일치 여부는 별도 확인합니다. 입력창을 만들기 전에 불러와 Streamlit 상태 변경 오류를 방지합니다.
- 정상 계산 시 새 평가 버전 ID로 자동 보관합니다. 재계산으로 이전 버전을 덮어쓰지 않습니다. 동일 계산의 저장 재확인은 같은 버전으로 재시도합니다. 평가 당시의 등기 출처 스냅샷과 세무조정 검토 이력도 보관합니다.
- 클라우드 저장 완료, 로컬 보존·클라우드 확인 필요, 영구 저장 확인 실패를 구분합니다. 저장 실패를 성공으로 표시하지 않습니다.
- 로컬 평가 이력과 등기 캐시는 잠금 후 최신 파일 재조회·병합·원자적 교체로 저장합니다. 읽을 수 없는 원본은 덮어쓰지 않습니다.
- 등기 복원은 신규 저장시각을 비교하고 비어 있지 않은 항목을 보존합니다. 식별번호 충돌, 애매한 동일 상호, 다른 기업의 자료 연결은 차단하고 과거 원본 키는 유지합니다.

## 데이터·권한·영향도

Supabase 테이블·컬럼·인덱스·RLS 변경 및 마이그레이션은 없습니다. 기존 고객 ID·company_uid·Storage·원본 파일·상담 이력은 변경하거나 삭제하지 않습니다. 기존 사용자 범위 조회를 그대로 사용하며 업체명을 공통 키로 사용하지 않습니다. 계산식, 세법 적용 기준, 전화번호 수집, Tilko 호출은 수정하지 않습니다.

등록 자료는 기존 클라우드 스냅샷·첨부파일·고객 히스토리에 계속 보관합니다. 이번 수정이 이미 덮어쓰거나 삭제된 과거 원본을 새로 복구하는 것은 아닙니다. 기기별 미전송 초안은 해당 브라우저 세션에 보관하며, 다른 기기·재접속에서 확인할 영구 저장은 클라우드 완료 상태를 확인해야 합니다. 완전히 동일한 등기 스냅샷을 여러 기기에서 동시에 수정하는 DB CAS/RPC는 이번 UI 패치 범위에 포함하지 않습니다. 기존 원본 첨부·이력과 새 평가 버전은 보존합니다.

## 사용 방법

1. 기업정보등록에서 기업을 선택하고 등기를 업로드합니다. 진행·저장 완료 또는 확인 필요 안내를 확인합니다.
2. 기업컨설팅에서 해당 기업의 주가평가를 엽니다. 상단의 등기 요약·상세를 확인합니다.
3. 다른 기기에서 새 자료를 등록했다면 ‘등록 자료 새로고침’을 누릅니다. 기존 평가와 차이가 있으면 원문·평가기준일을 검토한 후 ‘등록 등기값을 현재 평가에 반영’을 누릅니다.
4. ‘주가평가 계산’을 누르면 결과와 입력값이 새 버전으로 보관됩니다. 클라우드 완료인지 확인하고, 확인 필요라면 ‘저장 상태 다시 확인’을 사용합니다.
5. 다음 방문에는 ‘최근 평가 바로 열기’ 또는 하단의 현재 기업 평가 이력을 사용합니다. 저장 당시 결과는 별도 표시되며 새 계산식이나 새 자료로 조용히 다시 계산하지 않습니다.

관리자는 기존 사용자 범위·업체 선택·운영 조회 권한을 사용합니다. 추가 권한 설정이나 SQL 실행은 필요 없습니다.
